# Пробные занятия по физике

Страница INVARIANT с двумя сценариями. В ЕГЭ 24 задачи, в школьной физике 25 задач. У каждой темы есть рекомендуемый порядок. Задачи можно выбирать напрямую либо проходить по порядку.

## Запуск

Онлайн — [Пробное занятие по физике](https://inv1nced.github.io/zadachnik-oge/trial/).

Для локального запуска из корня репозитория:

```sh
python3 -m http.server 8781 --bind 127.0.0.1
```

Откройте [локальную страницу](http://127.0.0.1:8781/trial/). Интернет для локального запуска не нужен. Сервер нужен для загрузки модулей и банков браузером.

## Проведение урока

1. Выберите «ЕГЭ» или «10 класс». ЕГЭ начинается с кинематики, 10 класс — с энергии. Выберите другую тему или сложность в боковой панели.
2. Откройте полноэкранный режим для демонстрации задачи. «Показать интерактив» открывает модель. «Пуск» запускает движение, «Сброс» возвращает исходные параметры и первый кадр.
3. «Открыть на доске» передаёт условие и схемы штатной доске. Доска работает локально в этом браузере.
4. Открывайте подсказки и шаги решения по одному. Задания с устным ответом отмечайте после обсуждения.
5. Нажмите «План занятия» и выберите темы. Откройте отчёт для родителя, заполните поля по итогам встречи и скачайте файл или скопируйте текст.

Для звонка делитесь вкладкой с задачами. Прежде чем открывать локальную методичку или отчёт при показе всего экрана, остановите демонстрацию. Исходные методички и сведения об учениках хранятся отдельно от репозитория. Отчёт живёт в открытых окнах браузера до их закрытия или перезагрузки. Скачайте его перед завершением работы. Отчёт отправляется только вручную.

## Проверка

```sh
node trial/verify.mjs
node trial/verify.mjs http://127.0.0.1:8781/trial/
```

Для второй команды нужен `playwright-core` с установленным Chromium. Чтобы проверить через установленный Chrome, укажите путь к браузеру в `OGE_CHROME`. Тест запускает оба сценария на размерах 1470 × 956 и 390 × 844 и блокирует обращения за пределы адреса тестируемого сервера.

Автопроверка повторно использует правила чисел из `learning-core.js`. Для отдельных полей банка можно задать `decimals` для округления и `absoluteTolerance` для абсолютной погрешности. Ключи ответов, публичные подсказки и шаги решения даны в обезличенных банках `ege.json` и `school.json`. В браузере они раскрываются по действию или после правильного ответа.
