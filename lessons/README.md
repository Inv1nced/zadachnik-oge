# Уроки INVARIANT

## Публичные страницы

- `ege.html` — последовательность шести блоков, выбор экзамена, входы в банк и пробники.
- `lessons.html?exam=ege|oge` — списки уроков. Параметр `lesson` открывает карточку по стабильному строковому ID. Номер в курсе и внутренний ID кабинета хранятся отдельно.
- Пример прямой ссылки для общей сборки — `lessons.html?exam=ege&lesson=velocity-graph&stage=explain`. Доступные этапы — `diagnostic`, `explain`, `together`, `practice`, `review`, `homework`.
- Вход ОГЭ в сборке главной — ссылка `lessons.html?exam=oge` с текстом «Уроки ОГЭ» из `oge.html`. Прежние переходы к карточкам используют `index.html?block=…`, а переход в кабинет — `teach.html?view=lessons`.
- В сборке главной `ege.html` использует `entry/exam-preference.js` для запоминания выбранного экзамена. В отдельной ветке переключатель ОГЭ ведёт к списку уроков.
- ЕГЭ передаёт тему банку через `ege-bank.html?topic=<slug>`. Вход в пробники — `mocks.html?exam=ege`. При отсутствии страницы открываются материалы ФИПИ. Карты покрытия: [ЕГЭ](coverage/ege.md) и [ОГЭ](coverage/oge.md).

## Локальные закрытые исходники

Отдельная копия для ветки находится в `../invariant-lessons-private/`. В ней сохранены прежние разметка, план и авторские карточки ОГЭ. `curriculum-ege.txt` и `curriculum-oge.txt` содержат мастер-данные уроков, включая решения. `build-lessons.py` генерирует публичные JSON и локальный `lessons-data.js`. Публичный JSON содержит условия и подсказки. В кабинете остаются ключи, решения, критерии диагностики и рабочие записи.

После обновления материалов выполнить из корня репозитория:

```sh
python3 ../invariant-lessons-private/build-lessons.py .
```

Затем передать текущий пароль журнала только через stdin в `node scripts/protect-teacher.mjs ../invariant-lessons-private --workspace-only`. Скрипт собирает `teacher-workspace.enc.json` с ключом журнала. `--workspace-only` сохраняет прежнюю сборку отдельной методички ОГЭ. Шифротекст с рабочим паролем нужно проверить входом и передать с общей сборкой. Содержимое приватной папки хранится локально.

В закрытом кабинете `teach.html?view=lessons&exam=ege` показывает ЕГЭ, `teach.html?view=lessons` — ОГЭ. Урок ЕГЭ использует отдельное поле последнего занятия и отдельный диапазон ID. Доска, профиль, выдача, приём работ и восстановление старых ссылок используют механизмы прежнего кабинета. К прежней домашней работе новой нумерации методика не применяет.

## Проверки

```sh
node lessons/verify.cjs
OGE_PRIVATE_SOURCE=../invariant-lessons-private node scripts/verify-learning.cjs
node lessons/verify.cjs --browser
```

Для браузерной проверки доступен параметр `OGE_CHROME` и требуется `playwright-core`. При наличии закрытых исходников тест создаёт временный шифрованный кабинет со своим паролем и вымышленными профилями на локальном порту. Существующий регрессионный тест кабинета с исходными 56 занятиями запускается со старой копией `OGE_PRIVATE_SOURCE=../site-private-source node scripts/verify-study-flows.cjs`.

## Данные для общей сборки

Нужны опубликованный каталог ЕГЭ v1 и ID готовых карточек с проверенными ответами. После их получения следует проверить совпадение slug, подобрать задачи по каждому занятию и проверить прямые ссылки `ege-bank.html?task=<id>`.

Для кнопки выдачи кодов пробников нужен закрытый модуль агента 4, интерфейс его запуска, приватный набор вариантов и тестовый код для совместного прогона. Точку входа следует добавить в разметку приватного `teach.html` и упаковку кабинета.
