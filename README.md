# INVARIANT — подготовка к ОГЭ и ЕГЭ

Основное рабочее место: [teach.html](https://inv1nced.github.io/zadachnik-oge/teach.html).

При первом визите главная предлагает выбрать экзамен. Следующий визит открывает последний выбранный курс. В шапке курса есть переключатель, а адрес `index.html?choose=1` всегда открывает экран выбора. Действующий задачник по физике находится в [oge.html](https://inv1nced.github.io/zadachnik-oge/oge.html).

[Задачник ЕГЭ](https://inv1nced.github.io/zadachnik-oge/ege-bank.html) открывается из курса и из каждого урока. В задачнике 242 полных карточки с условиями и 2 321 ссылка на оригинальные задания ФИПИ. По темам можно идти в порядке уроков. Подборки по номерам разделяют задачи из тренировочного варианта и задания, подходящие для тренировки формата по спецификации 2027. Для локального просмотра оригиналов есть «Подключить полный банк». Выбери офлайн-файл INVARIANT один раз, чтобы видеть иллюстрации и условия в этом браузере. Черновики, прогресс и подключённые материалы хранятся на устройстве. [Данные и локальный импорт](ege-data/v1/SCHEMA.md).

## Провести урок

1. Выбрать ученика и занятие плана. «Перед уроком» — краткая памятка, диагностика и сценарий на 60 минут.
2. Пройти «Объясняем → Вместе → Практика». Тренажёры и доска открываются поверх урока. У задач исходного банка постоянные подписи «Блок N · №M»; авторские карточки подписаны отдельно.
3. Отмечать разобранные задачи. Во вкладке «Домашка» собрать подборку или выбрать готовую. Сохранить выдачу для текущего ученика и скопировать ему сообщение со ссылкой.
4. Ученик решает по ссылке и присылает сообщение с `RES-`. В «Проверке» открыть предпросмотр. Персональная выдача подставит профиль и версию. Для старого кода нужно выбрать ученика. Затем проверить объяснения, оставить комментарии и при необходимости прикрепить фотографии.
5. Скопировать разбор ученику и собрать разминку по ошибкам. После повторной проверки отметить освоение темы. Регулярно скачивать общую резервную копию.

Кабинет и преподавательский маршрут открываются по паролю прежнего журнала. Их разметка, сценарии и материалы зашифрованы AES-GCM; без расшифровки приложение не запускается. После входа исходный банк подключается автоматически. Выход выполняется кнопкой «Выйти из кабинета». Пароль не включён в исходники и резервные копии. Коды уроков расшифровываются только после входа. При включённом «Запомнить это устройство» ключ доступа сохраняется в текущем браузере между открытиями; без этой отметки — только в текущей вкладке. Текст пароля не сохраняется. «Выйти из кабинета» сбрасывает оба способа входа. Не оставляйте открытый кабинет на общем компьютере. Это шифрование статических материалов, а не серверные аккаунты или разграничение пользователей.

## Материалы

- 56 занятий по всему маршруту ОГЭ: механика, тепловые явления, электричество и магнетизм, оптика, квантовые явления, смешанная практика и контроль.
- 464 уникальные авторские учебные карточки, включая графики; контрольные занятия повторно используют подходящие карточки. Это учебная практика, а не новый официальный банк ФИПИ.
- Исходные 602 задания сохранены, включая шифрование закрытых блоков и изображения.
- В новых разделах задачи ФИПИ открываются в тех же карточках, что и практика механики. Условия, числовые данные, варианты выбора и ключи доступны в `bank/fipi-native.js`, иллюстрации хранятся рядом в `bank/figures/`. Формулировки переоформлены по указанным номерам открытого банка. Для кратких ответов используется общая автопроверка, для экспериментов — разбор на доске. Остальные номера доступны в каталоге.
- Авторские дополнения с постоянной нумерацией «Блок N · Доп. №M» доступны в тематических блоках. Измерения, анализ эксперимента, работа с текстом и практические работы открываются отдельными подборками.
- Автоподбор ДЗ в кабинете использует задачи текущей темы, чередует форматы и учитывает отмеченные и уже выданные карточки. Состав можно проверить и поправить перед выдачей.
- [Каталог ФИПИ](https://inv1nced.github.io/zadachnik-oge/fipi-mechanics.html?section=all) содержит 1 506 уникальных номеров. Снимок `bank/fipi-tasks.js` собран со всех страниц тематических разделов [ege-fipi.ru](https://ege-fipi.ru/oge-physics) и сверён с прежним списком из 645 номеров механики. Темы сопоставлены с блоками в `bank/fipi-index.js`. Один номер может появляться в нескольких блоках, его отметка общая.
- 48 задач прошлой подборки доступны через «Авторская практика» и в кабинете через «Домашка → Мой банк ФИПИ и других источников → Блок банка».
- Карта покрытия, источники и полная методичка: `tutor-plan/`. Основа маршрута — проект документов ФИПИ–2027, проверенный 31 октября 2026 года. План не означает независимую проверку каждого ключа исходного банка и не гарантирует отметку.

## Данные

Профили, журнал уроков, подборки и результаты хранятся локально в браузере. Фото — в IndexedDB. Общая JSON-копия включает записи старого задачника, журнала и плана, доски и фотографии; импорт объединяет данные, сохраняя существующие отметки. Приложение не обеспечивает вход нескольких преподавателей, облачную синхронизацию или самостоятельную отправку фотографий с другого устройства. Фотографии ученики пока присылают преподавателю привычным способом.

Доска сохраняет снимок в контексте ученика и задачи. Перед сменой задачи и закрытием выполняется сохранение. Совместное подключение использует прежние внешние каналы связи; локальное сохранение не подтверждает надёжность внешнего сервиса.

## Защищённые исходники

Редактируемые исходники кабинета и маршрута вынесены за пределы каталога GitHub Pages: `../site-private-source/`. В репозитории опубликованы только зашифрованные `teacher-workspace.enc.json` и `tutor-plan/teacher-plan.enc.json`; преподавательские JS/Markdown-файлы напрямую больше не раздаются. Ранее опубликованные версии материалов могли сохраниться в истории публичного репозитория; эта защита не отзывает уже скачанные копии. Личные записи учеников никогда не публикуются в репозитории.

После правок запустить `node scripts/protect-teacher.mjs` из корня репозитория, передав пароль журнала только через stdin. Пароль не хранить в аргументах, скриптах, файлах или коммитах. Проверка автоматически использует локальные закрытые исходники; без них выполняет только публичные проверки с явным сообщением об ограничении.

## Разработка и проверка

Статический сайт без сборки. Локальный запуск:

```sh
python3 -m http.server 8794 --bind 127.0.0.1
node scripts/verify-learning.cjs
```

Скрипт проверяет строгий числовой ввод, ручную проверку, состав всех 56 занятий, уникальность карточек, площади графиков и синтаксис встроенных скриптов. Дополнительно проверять в браузере выдачу домашки, ученическую сдачу, приём результата, подключение закрытого банка, доску и резервную копию с фото.

Для браузерной проверки установить `playwright-core` и запустить `node scripts/verify-study-flows.cjs`. Можно указать путь к установленному Chrome в `OGE_CHROME`. Скрипт поднимает локальный сервер, открывает готовые домашки и проверяет черновики, сдачу, автопроверку и мобильные страницы. При наличии закрытых исходников он также собирает отдельный тестовый кабинет с вымышленными профилями и проверяет импорт и разминку. На GitHub публичные проверки запускаются при push в `main` и в pull request.

Для готовых домашних работ есть короткие ссылки `oge.html#set=impulse`, `#set=dynamics`, `#set=friction` и `#set=ratio`. Их состав находится в `assignments/`. Ранее выданные ссылки на главную с параметрами банка, домашек и доски переходят на `oge.html` с теми же параметрами. Коды результатов поддерживаются. Черновики теста и домашки можно вести параллельно в одном браузере.

GitHub Pages публикует корень ветки `main`. Личные записи, резервные копии и расшифрованный банк не коммитить.

## Подключение переключателя в курсе ЕГЭ

В `ege.html` подключить в `head` скрипт `entry/exam-preference.js` без `defer` и стили `entry/exam-handoff.css`. Скрипт применяет плавное появление только после перехода с главной. В шапке курса разместить переключатель с текущим ЕГЭ:

```html
<nav class="exam-switch" aria-label="Курс по физике">
  <a href="oge.html" data-exam-choice="oge">ОГЭ</a>
  <a href="ege.html" data-exam-choice="ege" aria-current="page">ЕГЭ</a>
</nav>
```

Ссылка «Задачник» в прежнем кабинете ведёт на `oge.html`. Старый адрес iframe `index.html?workspace=1` поддерживается.

## ИИ-помощник

Ученик открывает лягушку кнопкой «Задать вопрос». Кнопка в карточке задачника или домашней работы прикладывает её текст к вопросу. Помощник передаёт введённый вопрос и приложенный текст модели Gemma 4 в Cloudflare Workers AI. Во время теста помощник закрыт.

GitHub Pages раздаёт интерфейс. Обработчик вопросов запускается отдельно как Cloudflare Worker с SQLite Durable Object:

```sh
npx wrangler deploy --config frog-api/wrangler.toml
openssl rand -hex 32 | npx wrangler secret put FROG_QUOTA_SALT --config frog-api/wrangler.toml
```

В `frog-api.json` укажи HTTPS-адрес опубликованного Worker в поле `url`. Cloudflare Workers AI подключается через привязку `AI`. Секрет `FROG_QUOTA_SALT` используется для хеширования IP-адресов. При пустом адресе интерфейс сообщает, что ИИ ещё не подключён.

Сервер выдаёт пять вопросов в день и проверяет два счётчика одновременно для браузера и публичного IP-адреса. Устройства одной сети делят пять вопросов. Счётчики сбрасываются в полночь по Москве. Сервер также резервирует часть бесплатного лимита Cloudflare на каждый запуск модели и прекращает приём вопросов после исчерпания общего бюджета. Ошибка до первого фрагмента возвращает вопрос в лимит ученика. Переписка остаётся в текущей вкладке.
